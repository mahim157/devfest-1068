# Smart Escape

Smart Escape is a frontend-only emergency evacuation route simulator.

## Features

- Interactive building map
- Lowest-cost route using Dijkstra's algorithm
- Blocked node handling
- Blocked corridor handling
- Closed exit handling
- Automatic route recalculation
- Bangla and English support
- Building JSON import
- Reset simulation

## Tech Stack

- React
- JavaScript
- Vite
- CSS
- SVG
- Dijkstra's Algorithm

## Run Locally

```bash
npm install
npm run dev
